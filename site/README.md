# ОБРАЗ — локальный прототип

Простой, но рабочий прототип сервиса «цифровой гардероб + ИИ-стилист», собранный по итогам
анализа пяти российских проектов (см. `../ANALYSIS.md`).

## Что внутри

| Файл | Назначение |
|---|---|
| `index.html` | вся страница: hero, шаги, гардероб, чат, примерка, проверка покупки, тарифы, FAQ |
| `assets/css/style.css` | оформление, адаптив, анимации |
| `assets/js/app.js` | данные гардероба, алгоритм подбора образов, чат-стилист, localStorage |
| `assets/img/*.svg` | иконка сайта и иллюстрации «до / после» для примерки |

## Что реально работает (не картинки)

1. **Гардероб** — 18 демо-вещей, поиск, фильтры по категориям, добавление своей вещи
   с фото (сжимается в браузере до 320 px) и удаление. Всё хранится в `localStorage`.
2. **Сборщик образов** — настоящий алгоритм: повод + температура → сезон, «идеальная
   теплота» слоёв, сочетаемость цветов, свежесть вещи (что не надевали неделю). Каждый
   образ сопровождается объяснением «почему так».
3. **История носки** — кнопка «Надеть сегодня» пишет вещь в журнал, обновляет статистику
   и список «что не носится».
4. **AI-стилист** — чат по правилам: собеседование, свидание, спорт, «с чем носить X»,
   «что докупить», погода, тарифы, приватность. Отвечает по текущему гардеробу.
5. **Примерка** — слайдер «до/после» (перетаскивается мышью, пальцем и стрелками).
   Честно помечен как демонстрация.
6. **Проверка покупки** — выбираете категорию и цвет, получаете «есть с чем носить»,
   «стоит подумать» или «это дубль», с числом сочетаний и списком незакрытых слотов.

Никаких внешних API, аналитики, куки и отправки данных на сервер — только статика.

## Запуск

Сервер уже поднят: **http://127.0.0.1:8123/**

Если нужно поднять заново:

```powershell
cd site
python -m http.server 8123 --bind 127.0.0.1
```

или просто откройте `index.html` двойным щелчком — всё работает и с `file://`,
кроме сохранения в localStorage в некоторых браузерах.
