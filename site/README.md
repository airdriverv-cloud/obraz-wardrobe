# ОБРАЗ — прототип

Статика без сборки: открывается любым сервером или прямо из файла.

## Страницы

| Файл | Вариант |
|---|---|
| `index.html` | карточки вещей — фотографии каталога |
| `icons.html` | то же самое, но с линейными иконками в цвете вещи |

## Что реально работает

1. **Каталог 92 фото** — фильтры по типу, поиск по названию и цвету, перемешивание.
2. **Воронка 100 500 SKU** — шесть фильтров считаются по всем позициям каталога,
   счётчики и полосы обновляются при смене повода, температуры и пола.
3. **Три комплекта на сегодня и на завтра** — разные «настроения» (работа, комфорт, вечер),
   штраф за повтор вещи между вариантами, учёт истории носки.
4. **Примерка на четырёх моделях** (Мила, Ника, Марк, Тимур) — векторный манекен,
   одежда рисуется силуэтами в цвете выбранных вещей.
5. **Своё фото** — загрузка в полный рост, наложение одежды с ползунками масштаба и сдвига.
6. **Чат-стилист** — отвечает по правилам, знает текущий комплект и цифры воронки.
7. **Кнопка «Надеть»** — вещь уходит в историю носки, комплекты пересобираются без неё.

## Файлы

```
index.html, icons.html      разметка (обе страницы идентичны, отличается data-mode)
assets/css/style.css        всё оформление
assets/js/items.js          список фото (генерируется из data/items.json)
assets/js/data.js           справочники, цветовые правила, модели
assets/js/outfits.js        каталог 100 500 SKU, воронка, сборка комплектов
assets/js/model.js          манекен и векторная одежда
assets/js/app.js            интерфейс, оба режима отрисовки
assets/img/items/*.webp     92 фото вещей
```

## Запуск

```powershell
python -m http.server 8123 --bind 127.0.0.1
```

Данные не покидают браузер: своё фото обрабатывается через FileReader и никуда не отправляется.
