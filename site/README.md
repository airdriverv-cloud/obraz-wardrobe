# ОБРАЗ — прототип (многостраничный)

Статика без сборки. Каждый раздел — отдельная страница, навигация в шапке.

## Страницы

| Файл | Раздел | Что внутри |
|---|---|---|
| `index.html` | Главная | образ дня, 5 плиток-переходов, мини-витрина |
| `catalog.html` | Каталог | витрина селлеров, фильтры по цене и доставке, корзина образа, оформление |
| `stylist.html` | ИИ-стилист | воронка 100 500 → 3 комплекта, комплекты на сегодня/завтра, чат |
| `fitting.html` | Примерка | 4 модели, сборка образа, загрузка своего фото |
| `delivery.html` | Доставка | калькулятор по городу и весу, 5 служб, условия возврата |
| `sellers.html` | Селлерам | создание карточки, расчёт комиссии, сравнение с WB/Ozon, FAQ |

## Переключение «фото / иконки»

Одна и та же страница в двух оформлениях: `catalog.html?mode=icons`.
Режим запоминается в `localStorage` и переносится между страницами.
Спрайт иконок — `assets/img/sprite.svg`, подключается через `<use href="...">`.

## Скрипты

```
items.js      список фото (генерируется из data/items.json)
data.js       справочники, цветовые правила, модели
outfits.js    каталог 100 500 SKU, воронка отсева, сборка комплектов
model.js      манекен и векторная одежда
assets/img/models/*.webp  сгенерированные фото моделей
ui.js         режим отрисовки, навигация, helpers
home.js       образ дня и мини-витрина
catalog.js    витрина, корзина, оформление
stylist.js    воронка, варианты, чат
fitting.js    модели, примерка, своё фото
delivery.js   калькулятор доставки
seller.js     форма карточки и расчёт комиссии
```

## Запуск

```powershell
python -m http.server 8123 --bind 127.0.0.1
```

Данные не покидают браузер: фото обрабатывается через FileReader, корзина живёт в памяти вкладки.
