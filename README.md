# ОБРАЗ — цифровой гардероб и ИИ-стилист

Прототип сервиса «цифровой гардероб + AI-стилист» и аналитический отчёт по рынку fashion-tech.
Собран по итогам разбора пяти российских проектов: Tidy, YeetStyle, Garde, Wearly, LOOKLAB.

## Что в репозитории

| Путь | Что это |
|---|---|
| `site/` | работающий прототип: лендинг + демо-гардероб, сборщик образов, чат-стилист, примерка, проверка покупки |
| `ANALYSIS.md` | аналитический отчёт: 5 исходных сайтов, 22 конкурента, выводы и рекомендации |
| `ANALYSIS.pdf` | тот же отчёт в PDF |
| `start-server.ps1` | локальный запуск прототипа на `http://127.0.0.1:8123/` |

## Прототип

Статика без сборки, бэкенда и внешних API. Всё работает в браузере:

- **гардероб** — 18 демо-вещей, поиск, фильтры, добавление своей вещи с фото (сжатие на клиенте);
- **сборщик образов** — детерминированный алгоритм: повод + температура → сезон, теплота слоёв,
  сочетаемость цветов, свежесть вещи; каждый образ с объяснением «почему так»;
- **история носки** — кнопка «Надеть сегодня», статистика и список «что не носится»;
- **чат-стилист** — отвечает по правилам и по вашему гардеробу;
- **проверка покупки** — «есть с чем носить / стоит подумать / это дубль»;
- **примерка** — слайдер «до/после», честно помечен как демонстрация.

Данные хранятся в `localStorage`, на сервер ничего не уходит.

## Запуск

```powershell
cd site
python -m http.server 8123 --bind 127.0.0.1
```

или `.\start-server.ps1`. Достаточно любого статического сервера — сборка не нужна.

## Отчёт

`ANALYSIS.md` / `ANALYSIS.pdf` — разбор пяти сайтов, таблица 22 конкурентов (включая закрытые
The Yes и Save Your Wardrobe), свободные ниши, рекомендации по позиционированию, воронке,
тарифам, технологиям, SEO и метрикам.
