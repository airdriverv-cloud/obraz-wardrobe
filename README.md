# ОБРАЗ — цифровой гардероб и ИИ-стилист

Прототип сервиса «цифровой гардероб + AI-стилист» и аналитический отчёт по рынку fashion-tech.
Собран по итогам разбора пяти российских проектов: Tidy, YeetStyle, Garde, Wearly, LOOKLAB.

**Живая демонстрация:** https://airdriverv-cloud.github.io/obraz-wardrobe/
**Вариант с иконками:** https://airdriverv-cloud.github.io/obraz-wardrobe/icons.html

## Две версии страницы

| Вариант | Файл | Что внутри |
|---|---|---|
| С фотографиями | `site/index.html` | карточки вещей — реальные фото каталога |
| С иконками | `site/icons.html` | те же данные, но линейные SVG-иконки в цвете вещи |

Переключатель — в шапке страницы. Обе версии используют один и тот же JS и одни данные,
отличается только способ отрисовки карточки (`data-mode` на `<body>`).

## Что в репозитории

| Путь | Что это |
|---|---|
| `site/` | работающий прототип (статика, без сборки) |
| `site/assets/js/outfits.js` | виртуальный каталог 100 500 SKU и воронка подбора |
| `site/assets/js/model.js` | манекены четырёх моделей и векторная одежда на них |
| `site/assets/js/data.js` | справочники, цветовые правила (нейтрали, родственные, комплементарные тона) |
| `site/assets/img/items/` | 92 фото вещей (WebP, 420×420, фон выбелен) |
| `tools/fetch_items.py` | скачивание и нормализация фото из открытого датасета |
| `tools/build_items_js.py` | `items.json` → `items.js` |
| `ANALYSIS.md` / `ANALYSIS.pdf` | аналитический отчёт: 5 сайтов, 22 конкурента, рекомендации |
| `tools/md2docx.py` | сборка PDF из Markdown |

## Как работает подбор

1. **Каталог.** 92 фотографии × размеры 42–50 × бренды × сезоны = **100 500 позиций**.
   Хранится компактно: шесть типизированных массивов на 100 500 записей (~0,6 МБ), а не 100 500 объектов.
2. **Воронка.** Шесть фильтров по очереди — пол и типаж, сезон и температура, повод,
   размер, цветовая совместимость, нужные слои. Каждый шаг считается по всем позициям,
   числа на странице настоящие.
3. **Сборка.** Из выживших вещей берутся уникальные модели, отбрасывается то, что надевали
   за последние 7 дней, и собираются 3 комплекта с разными «настроениями»: работа, комфорт, вечер.
4. **Примерка.** Комплект рисуется на одной из четырёх моделей (2 девочки, 2 мальчика) —
   силуэт и цвет каждой вещи настоящие. Можно загрузить своё фото и подогнать одежду ползунками.

## Запуск

```powershell
cd site
python -m http.server 8123 --bind 127.0.0.1
```

или `.\start-server.ps1`. Сборка не нужна — обычная статика.

## Отчёт

`ANALYSIS.md` / `ANALYSIS.pdf` — разбор пяти сайтов, таблица 22 конкурентов (включая закрытые
The Yes и Save Your Wardrobe), свободные ниши, рекомендации по позиционированию, воронке,
тарифам, технологиям, SEO и метрикам.
